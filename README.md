# ResolveAI

A production-style frontend prototype for an agentic grievance redressal ecosystem.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite (normally `http://localhost:5173`).

## Build

```bash
npm run build
```

The app uses centralized mock data in `src/data/`, reusable React components, React Router, Recharts, and an API-ready mock service in `src/services/mockApi.js`.
